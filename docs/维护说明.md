# 瞄店维护说明

本说明面向维护者。页面内仅保留运营决策所需的口径与假设，不要求访客安装任何软件。

## 目录与职责

| 路径 | 职责 |
|---|---|
| `src/index.html` | 纯中文页面结构、三个业务标签、语义与可访问名称 |
| `.gitattributes` | 保留文件字节，跨系统检出不自动转换换行，维持已核验摘要 |
| `src/styles.css` | 视觉变量、图表和表格样式、响应式布局 |
| `src/app.mjs` | 聚合数据导入、图表、筛选、商家诊断、滑块情景与页面状态 |
| `src/dashboardData.json` | 唯一业务数据输入，未压缩UTF-8小于80,000字节 |
| `scripts/prepare_dashboard.py` | 只读原始输入，离线生成聚合数据及中文商家映射 |
| `scripts/build.mjs` | 将结构、样式、脚本和聚合数据内嵌为单HTML |
| `scripts/verify.mjs` | 检查构建产物、体积、禁用资源及路径约束 |
| `scripts/preview.mjs` | 仅监听本机的临时预览，支持仓库子路径 |
| `scripts/package_release.py` | 输出独立源码包与静态包，逐件记录并回读校验大小和摘要 |
| `tests/test_dashboard.py` | 数据口径、中文映射、边界与可重现性测试 |
| `tests/test_runtime.mjs` | 新版静态运行和业务交互逻辑检查 |
| `docs/数据口径与交叉核验.md` | 精确指标定义、选样与回放方法、实测交叉核验 |
| `docs/文件删改清单.md` | 新文件、旧资源退役、保留与恢复说明 |
| `evidence/data-checks.json` | 不含私人标识的数据核验回执 |
| `evidence/acceptance-checks.json`、`evidence/screenshots/` | 本地验收摘要与桌面、手机截图，不进入网页运行包 |
| `docs/本地验收记录.md` | 当前构建结果、交互实测、风险和未验证边界 |
| `dist/index.html` | 面向访客的完整单文件页面，严格小于150,000字节 |
| `dist/app/index.html`、`dist/case.html` | 旧入口的相对路径轻跳转，不复制一份业务数据 |
| `dist/.nojekyll` | GitHub Pages静态标记，可为空文件，不是待下载的业务文件 |
| `dist/CODE_LICENSE.md`、`dist/SOURCE_LICENSE.md` | 随静态作品分发的代码许可说明与数据署名许可 |

## 仅修改文案或布局

修改`src/`中的结构、交互和样式后执行：

```powershell
node scripts/build.mjs
node scripts/verify.mjs
node --test tests/test_runtime.mjs
```

不要直接编辑构建后的`dist/index.html`，否则后续重建会覆盖人工差异。页面标题、导航、诊断文案和界面名称统一为“瞄店”。技术文件名可以沿用源码约定，但葡萄牙语、未翻译品类和原商家标识不能进入展示数据。

## 更新聚合数据

原始压缩包位于私人原项目的`data/raw/`，原分析库位于其`data/processed/`。预处理只读这些输入，不运行会覆盖原库的旧流水线，不读取或公开旧模拟处置库。

```powershell
python scripts/prepare_dashboard.py --source ../../olist_project
python scripts/prepare_dashboard.py --source ../../olist_project --check
python -m unittest discover -s tests -p test_dashboard.py
node scripts/build.mjs
node scripts/verify.mjs
node --test tests/test_runtime.mjs
```

`--source`是原项目目录，不是要公开发布的文件夹。若原项目存放位置不同，显式指定正确路径。`--check`重算并比较已有聚合数据，不写业务数据文件。需要保存新核验回执时，使用预处理脚本提供的`--evidence`参数，并给出新证据路径；公开前检查其中不含原始标识、私人文件路径或密钥。

更新不能只替换几项前端数字。必须重新执行原始输入校验、评价去重、时间有效性、中文映射、商家分层与回放分布；同步指标字典、分母及样本限制。数据不足时显示空值或缺少样本，不伪造连续曲线、商家增长率或干预效果。

## 体积与运行约束

- `dashboardData.json`以未压缩UTF-8字节计量，必须小于80,000字节，不能拿压缩后的网络体积替代。
- 构建后的完整`dist/index.html`必须小于150,000字节，聚合数据只内嵌一次。
- 页面不运行数据下载请求、后台计算线程、动态数据导入、第三方字体、访问统计或镜像请求。
- 不发布原始压缩包、SQLite、旧明细资源、原商家标识、客户信息、评价正文、私人环境配置、密钥、缓存或恢复包。
- 超限先检查重复文案、重复字段和无用展示数据；不得为压缩体积删掉异常样本、改变指标定义或将未检验结果写成通过。

完整历史证据、旧规则与旧接口测试在旧项目和恢复历史保留，不进入本版静态包。它们的保留不意味着访客还需要下载这些资源。

## 本地预览与离线检查

先完成构建，再执行：

```powershell
node scripts/preview.mjs
```

脚本只监听本机，并输出临时地址；当前预览地址为`http://127.0.0.1:4184/olist-merchant-operations-dashboard/`。它同时检查现有GitHub Pages仓库子路径，避免根路径部署能用、项目路径失效。预览有30分钟期限，停止时在启动窗口按Ctrl+C；需要继续预览时先确认原进程已停止，不能因一次观察超时就重复启动。

`dist/index.html`已内嵌全部业务数据、样式与交互，适合下载后离线展示；实际浏览器、设备和离线条件仍须记录。业务标签切换、商家筛选与滑块使用已载入数据，无需等待远程接口。

本地加载速度与中国大陆首次网络访问是两项不同验收。网络首访必须记录设备、浏览器、运营商、流量或无线网络、是否关闭代理、测试时间和成功范围。域名解析或首页状态成功不能代替图表、筛选、商家诊断和规则交互成功，更不能直接承诺免VPN一秒打开。

## GitHub Pages与发布包

仓库标识继续使用`olist-merchant-operations-dashboard`。本版所有兼容跳转使用相对路径，适配`/olist-merchant-operations-dashboard/`，不依赖域名根目录。

发布候选只取经过验证的`dist/`内容及许可材料；源码、测试和维护文档属于源码交付，不直接当作网页运行目录。`dist/.nojekyll`为空是正常静态标记；不要因此漏掉其他有正文的文件，也不要把空标记当作损坏的聚合数据。

生成新的交付目录，不覆盖旧包：

```powershell
python scripts/package_release.py --output ../../outputs/miaodian-v2-static/release
```

输出包含`miaodian-source.zip`、`miaodian-static.zip`及`release-manifest.json`。若目录已存在，选择新的输出目录；脚本不会清理或删除旧文件。清单记录每个归档成员的字节数及SHA-256，并从ZIP回读检查。静态包只含六件文件，不含截图或原始数据；源码包另含复现脚本、测试、文档及验收证据。

现有公开测试站、旧站与`main`保留。此次构建验证不自动改变Pages发布源、部署设置、主分支、仓库标识或主要展示网址。准备发布时先核对目标分支、实际文件清单和摘要；发布后核对实际提交及公网正文，再执行完整业务和真实手机验收。尚未发布的构建不能标成已经上线。

不创建收费资源，不购买域名，不修改域名解析、网络防护或访问权限。需要这些改变时，应先说明具体范围并取得对应授权。
