# 部署方案与审计

核查日期：2026-10-30。本文区分本地源码检查、平台官方规则和仍待验收的事项；公开部署与仓库地址以最终交付报告为准。

## 选择：静态网站与浏览器内计算

本项目数据固定、没有实时业务接入，处置记录只用于个人演示。采用方案 B：从现有 SQLite 只读导出必要字段，保留全部历史订单和商品归属；浏览器 Web Worker 承担筛选、聚合与指定时点规则回放；模拟记录保存在当前浏览器。保留既有三页和业务口径，不引入账号或远程写库。

本次发布通过 Sites 原生流程托管 `dist/`；Cloudflare Pages、GitHub Pages 是同一静态产物的备选部署平台。本项目未启用付费云实例、D1、R2、第三方付费数据库或购买域名。Sites 的费用和配额取决于当前账号、工作空间及服务条款，不能把 Cloudflare Pages 的公开免费政策直接视为 Sites 的费用承诺。

## 方案比较

| 维度 | A：Python 后端，例如 Render | B：静态托管与浏览器内计算（采用） | C：静态前端与轻量 API |
|---|---|---|---|
| 业务逻辑改动 | 保留 Python；需改监听、启动与共享状态 | 迁移 API 计算和状态保存；以原 API 对照验证 | 保留必要 API，增加跨服务配置 |
| 核心交互 | 可保留 | 可保留完整筛选、详情、任意有效时点和 R1—R4 | 可保留 |
| 冷启动 | 免费动态实例有休眠 | 无常驻业务进程；首次完整查询需下载并初始化主数据 | 后端仍可能冷启动 |
| 持久化 | 原模拟 SQLite 不适合临时磁盘；需另行安排 | 历史资源只读；操作记录按浏览器隔离、刷新可恢复 | 需决定远程数据库或浏览器保存 |
| 文件与资源 | 176,996,352 字节源库需要部署或下载；运行内存另测 | 主数据约 15.18 MB，单文件低于 25 MiB | 同时受前端和后端资源限制 |
| 更新复杂度 | 管理服务、环境、数据和迁移 | 导出、校验、发布静态目录 | 管理两套部署、错误链路和版本一致性 |
| 长期维护 | 较高 | 最低，适合固定历史作品集 | 较高，当前没有必须使用的远程能力 |
| 中国内地访问 | 需在目标网络实测 | 同样需实测；不能保证跨境网络延迟和稳定性 | 前后端两条链路均需实测 |

方案 B 的代价是浏览器初次处理约 15 MB 压缩数据，并承担解压后数据和索引的内存。默认经营汇总单独加载，复杂计算放在 Worker 中；手机是否流畅仍以真实设备和浏览器验收为准。它不能提供跨设备同步或真实多人协作，当前作品集也不需要这些能力。

中国内地访问尚无多地区、多运营商测试证据。跨境静态托管也会受网络影响；“全球 CDN”不能证明内地顺畅。Cloudflare 官方说明其中国网络是 Enterprise 的单独订阅，接入域名需有效 ICP 备案或许可，本项目没有购买或接入该网络。[中国网络官方说明](https://developers.cloudflare.com/china-network/)

## 静态版数据与状态边界

导出保留 99,441 笔订单和 112,650 条商品行，采用固定字段白名单。排除原数据库、客户标识、评价文本、地理坐标和旧模拟处置。清单及压缩文件哈希见 [manifest.json](../dist/data/manifest.json)。公开历史资源可以下载，不能宣称订单字段在浏览器内保密。

历史详情可看完整历史；回放详情通过与原 Python 一致的可见字段规则隐藏未来事件和事后标签。最终妥投等样本筛选本身依赖事后信息，仍需披露选择偏差。

模拟记录按网站源和浏览器配置文件隔离，不发送到服务。每次保存检查结构与容量，最多 500 个订单状态、1,000 条历史记录，总序列化文本限制 900,000 字符，备注最多 2,000 字符。到限或浏览器拒绝保存时报告失败，不显示成功；用户可一键重置。同一浏览器标签页共享状态，更换设备、清理网站数据或无痕会话结束不会保留。
