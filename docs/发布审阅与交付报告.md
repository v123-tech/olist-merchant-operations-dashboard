## 技术架构与取舍

采用静态网页＋压缩 JSON＋Web Worker，保留原三页和业务口径，将 API 计算迁移到浏览器。默认汇总独立读取，完整数据按需下载。没有常驻 Python 服务和服务端动作写库，避免后端休眠及临时磁盘状态丢失。

模拟操作只存当前网站的 localStorage；同一浏览器配置文件的标签页共享，不同浏览器或设备隔离。支持刷新恢复、一键重置；上限为 500 个订单状态、1,000 条历史记录和 900,000 字符。到限、损坏和拒绝保存时报告失败，不静默丢弃。

静态数据含完整历史结果；回放通过白名单遮蔽未来字段，保证页面与规则的信息条件，不能称为数据保密权限。样本事后筛选偏差保留披露。
