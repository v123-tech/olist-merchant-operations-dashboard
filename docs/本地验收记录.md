## 自动化与浏览器检查

17项Python测试、7项JavaScript测试及145项数据和静态检查全部通过。实际打包到HTML中的脚本另经语法解析，防止只检查源码而漏掉内嵌过程产生的错误。最初发现过特殊替换字符破坏内嵌脚本的问题，已使用函数替换保留原文并加入回归检查；修正后的页面加载与后续操作没有新增控制台错误。

浏览器检查使用本机临时预览及仓库子路径`/olist-merchant-operations-dashboard/`。桌面视口为1440×900及1366×768，手机尺寸为390×844；三种尺寸页面均无整个文档的横向溢出。手机导航和商家清单局部支持横向查看，图表采用窄屏尺寸，弹窗内部可以滚动。

| 检查 | 实际观察 |
|---|---|
| 总览 | 99,441、93.23%、62.42%、2.61%与聚合结果一致；折线点和品类条可读取中文样本与分母 |
| 商家清单 | 初始30家；高危与家居百货联合筛选为1家，刷新后保留；无样本筛选显示明确空态，清空后恢复30家 |
| 诊断 | 桌面与手机均能打开中文核心痛点和三条建议；关闭或Esc退出并恢复触发焦点 |
| 回放默认值 | 七天、不限金额：命中42笔，覆盖16笔历史差评，20%假设为3.2笔，人力3.5小时 |
| 滑块边界 | 零天为零；七天、五百雷亚尔为2笔、0.2笔情景挽回、约0.2小时；刷新保留参数，重置恢复默认 |
| 键盘 | 标签方向键切换；滑块Home、End生效；弹窗Esc退出 |
| 地址状态 | 当前业务标签、中文风险及品类、两个回放参数可随地址刷新恢复 |

两次本地刷新读取到页面初始化标记分别为45.20毫秒和43.10毫秒。该标记记录浏览器导航至初始化的本地时间，**不是公网下载耗时、首次绘制指标、内存测量或中国大陆移动网络首访结果**。没有用工具操作的墙钟耗时冒充页面性能。新版消除了旧版约15MB历史数据下载、解压与全量扫描，但不承诺托管网络本身始终一秒可达。

## 风险、恢复与剩余验收

前端不再提供原始订单查询与原规则处置接口；它们连同测试、Python、SQL和历史证据完整留在旧树。新回放属于本次88格点情景模型，不借用旧R1—R4测试来宣称兼容或真实业务效果。事后选样偏差、缺少取消时间、整单履约不能直接归责单个商家等边界均保留在界面和指标文档。

本次没有物理删除或批量移动旧文件。独立恢复分支`recovery/accepted-v2`仍指向`77297aca42b4ec13561d5668fce766ab2ab74589`；另有未改动的旧源码目录。需要回看时在另外目录恢复，不在当前有工作时强制检出旧树。详见[逐文件清单](文件删改清单.md)与[维护说明](维护说明.md)。

打包脚本会拒绝原始ZIP、SQLite、CSV、私人配置、密钥形态、缓存及符号链接；源码包和六文件静态包分别生成并回读核验。最终交付清单记录每件文件及归档摘要。

公开网站仍须用实际发布正文与提交核对品牌及内容，再验三个业务标签、HTTPS、旧入口相对跳转和真实手机首访。大陆验证须分别记录首页请求、资源完整性、完整业务交互及计时；本地或境外结果不能代替该验收。尚未取得这些结果时，完整线上目标保持未完成。
